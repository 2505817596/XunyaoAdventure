# 初始化配置

## 模块定位

初始化配置用于管理新账号和创建角色时获得的基础内容。

配置不写死在代码中，统一由 `gameplay.json` 控制。

## 配置文件

路径：

```text
App_Data/Configs/gameplay.json
```

结构：

```json
{
  "version": 1,
  "initialRole": {
    "monsterTemplateIds": []
  },
  "initialAccount": {
    "level": 1,
    "copper": 0,
    "defaultStageId": "",
    "formationSize": 5
  }
}
```

字段说明：

- `version`：配置版本。
- `initialRole.monsterTemplateIds`：创建角色时赠送的妖怪模板 ID 列表。
- `initialAccount.level`：新账号初始等级。
- `initialAccount.copper`：新账号初始铜钱。
- `initialAccount.defaultStageId`：默认选择关卡。
- `initialAccount.formationSize`：默认阵容数量。

## 后台页面

路径：

```text
/admin/gameplay
```

功能：

- 配置初始账号等级。
- 配置初始铜钱。
- 配置默认关卡。
- 配置默认阵容数量。
- 使用多选下拉框选择创建角色赠送妖怪。
- 保存后写入 `gameplay.json`。

## 创建角色流程

创建角色时：

```text
写入角色名和创建时间
 -> 读取 gameplay.json 的 initialRole.monsterTemplateIds
 -> 按模板 ID 读取 monsters.json
 -> 为玩家创建对应 OwnedMonster
 -> 第一个赠送妖怪设为收藏
 -> 保存账号
```

如果初始妖怪配置为空，创建角色成功后初始妖怪列表为空。

## 资源来源边界

创建角色只负责发放初始妖怪。

装备、道具、碎片由其他系统发放：

- 任务奖励
- 副本奖励
- 聚妖台掉落
- 邮件附件
- 后台/GM 发放
- 后续活动系统

## 校验规则

- 初始等级必须大于 0。
- 初始铜钱不能小于 0。
- 默认阵容数量必须大于 0。
- 默认关卡如果填写，必须存在于 `campaign.json`。
- 初始妖怪模板必须存在于 `monsters.json`。

## 当前限制

- 暂不支持创建角色时赠送道具、装备或碎片。
- 暂不支持按职业或阵营选择不同初始配置。
- 暂不支持新手引导分阶段发放奖励。
