# 任务系统

## 模块定位

任务系统用于把创建角色、妖怪养成、装备、聊天、战斗等玩法串成玩家目标。当前实现为主线任务链 + 每日任务。

## 任务配置

任务定义不写在代码里，统一配置在：

```text
App_Data/Configs/quests.json
```

后台入口：

```text
/admin/quests
```

后台可配置：

- 任务 ID
- 分类：主线 / 每日
- 标题
- 描述
- 触发事件
- 完成次数
- 前置任务
- 奖励列表

## 任务类型

| 类型 | 说明 |
| --- | --- |
| 主线 | 按前置任务顺序解锁，当前 UI 只突出展示当前推进项 |
| 每日 | 同时展示，完成后可领取奖励 |

主线任务不需要手动接取。前置任务领取奖励后，下一条主线自动解锁。

## 任务事件

当前支持事件：

- `CreateCharacter`
- `ViewMonsters`
- `MonsterLevelUp`
- `MonsterStarUp`
- `UseDemonEssence`
- `MonsterBreakthrough`
- `EquipItem`
- `UpgradeEquipment`
- `FuseEquipment`
- `EnterBattle`
- `ClearStage`
- `SendChat`

各玩法系统只负责上报事件，任务系统自行判断哪些任务需要增加进度。

## 奖励类型

当前支持：

- 铜钱：`Copper`
- 道具：`Consumable`

道具奖励通过物品模板 ID 发放到背包。

## 任务状态

`QuestState`：

- `QuestId`
- `Progress`
- `RewardClaimed`

任务状态使用 LiteDB 集合 `quest_states` 持久化。每个账号保存一份任务状态列表。

任务配置变更时：

- 新增任务会自动补初始状态。
- 删除任务会移除对应状态。
- 状态变更后立即保存。

## 页面规则

任务页路径：

```text
/quests
```

页面内容：

- 主线 / 每日 Tab
- 任务标题
- 任务描述
- 进度条
- 当前进度
- 奖励文本
- 领取按钮

未完成任务不可领取。完成后可领取。领取后标记为已领取并持久化。

## 当前限制

- 每日任务尚未按自然日重置。
- 暂未支持手动接取任务。
- 暂未支持指定关卡目标，例如“通关 1-1”。
