# 战斗初始化与对接

## 模块定位

战斗初始化负责把 Blazor Server 当前账号里的阵容数据转成 LeanCLR 战斗协议，并把必要的 UI 显示数据传给 Pixi。

## 初始化传输

1. Blazor Server 根据账号和阵容生成 `setupBytes`。
2. `setupBytes` 通过 JS module 的 `mountBattle` 参数直接传给浏览器。
3. Pixi/LeanCLR 只接收二进制初始化数据，不持有初始化配置表。

## Blazor 战斗页流程

战斗页 `/battle`：

1. 检查是否登录。
2. 检查是否创建角色。
3. 检查 `Session.BattleMonsterIds` 是否为空。
4. 根据 ID 从账号妖怪列表取出上阵妖怪。
5. 调用 `BattleDemoSetupFactory.CreateSetupBytes(selectedMonsters)`。
6. 生成 `heroes` UI 元数据：
   - `unitId`
   - `name`
   - `portraitUrl`
   - `unitAssetId`
   - `stage`
   - `star`
7. 通过 JS module 导入 `/battle-client/assets/battle-view.js?v=jsmodule-11`。
8. 调用 `mountBattle(element, options)`。

## mountBattle 参数

```text
setupBytes：LeanCLR 战斗初始化二进制
heroes：战斗头像和显示元数据
assetBaseUrl：/battle-client/
onExit：Blazor DotNetObjectReference，用于退出战斗回调
```

## LeanCLR 加载

Pixi 战斗模块会加载：

- `lean.js`
- `lean.wasm`
- `mscorlib.dll.bytes`
- `netstandard.dll.bytes`
- `System.Numerics.dll.bytes`
- `XunyaoAdventure.Battle.Core.dll.bytes`

优先尝试 `.br` 压缩文件，如果浏览器不能直接使用，会尝试前端 Brotli 解压。

## 战斗循环

- 逻辑帧间隔：100ms。
- 固定步长：`1 / 10`。
- 每帧：
  1. JS 编码输入命令。
  2. 调用 LeanCLR `App.Tick`。
  3. 读取输出事件。
  4. Pixi 渲染移动、受击、飘字、血条、波次等表现。

## 退出战斗

Pixi 暂停菜单点击退出：

1. JS 调用 `onExit.invokeMethodAsync("ExitBattle")`。
2. Blazor `ExitBattle` 导航到主页 `/`。
3. Blazor 组件释放时调用 `disposeBattle`。
