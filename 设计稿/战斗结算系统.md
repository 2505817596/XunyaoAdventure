# 战斗结算系统

## 模块定位

战斗结算系统负责在 LeanCLR/Pixi 战斗结束后通知 Blazor Server，由服务端判断胜负、发放关卡奖励、记录首通状态，并展示结算页。

## 回调流程

```text
LeanCLR 输出 battleEnded
 -> Pixi main.ts 检测 battleEnded
 -> 判断 winner 是否 TeamA
 -> 调用 Blazor BattleEnded(victory)
 -> CampaignStore.CompleteBattle
 -> 写入 GameSession.LastBattleResult
 -> 跳转 /battle/result
```

胜利判断：

```text
winner == TeamA => 胜利
否则 => 失败
```

## 结算数据

结算结果模型 `CampaignBattleResult`：

- `Victory`：是否胜利。
- `StageCode`：关卡编号。
- `StageName`：关卡名。
- `Rewards`：获得奖励。
- `FirstClear`：是否首次通关。
- `NextStageCode`：下一关编号。

结算结果保存在 `GameSession.LastBattleResult`，结算页读取后展示。

## 奖励规则

当前胜利奖励：

```text
铜钱 = 500 + 难度 * 160
经验药水 = 2 + 难度
```

首次通关额外奖励：

```text
灵魂石 = 3 + 难度 * 2
```

难度 4 及以上额外奖励：

```text
妖元 x1
```

失败规则：

- 不记录通关。
- 不发放奖励。
- 结算页显示失败和“未通关，没有获得奖励”。

## 首通记录

`CampaignStore` 当前用内存字典记录每个账号已通关关卡：

```text
userName -> cleared stage ids
```

服务重启后首通记录会丢失。后续接数据库时需要持久化。

## 结算页

页面路径：

```text
/battle/result
```

展示内容：

- 胜利 / 失败。
- 关卡编号和关卡名。
- 首次通关或再次通关。
- 下一关编号。
- 奖励列表。
- 继续副本。
- 返回主页。

## 当前限制
