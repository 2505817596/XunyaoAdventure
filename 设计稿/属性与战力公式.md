# 属性与战力公式

## 模块定位

属性系统负责把妖怪等级、星级、阶级、妖元、装备状态转成战斗属性；战力系统负责给 UI 一个快速强度评分。

## 属性字段

当前妖怪完整属性为：

- 力量成长
- 智力成长
- 敏捷成长
- 力量
- 智力
- 敏捷
- 最大生命值
- 物理攻击力
- 魔法强度
- 物理护甲
- 魔法抗性
- 物理暴击
- 生命回复
- 能量回复
- 打断阈值

详情页当前展示最终战斗属性，不展示成长字段。

## 主属性

妖怪主属性有三种：

- 力：偏前排，生命和物理承伤更高。
- 智：偏法术，魔法强度和魔抗更高。
- 敏：偏输出，敏捷、物理攻击和暴击更高。

## 基础成长

玩家妖怪的基础属性来自后台 JSON 配置 `App_Data/Configs/monsters.json`。

每个妖怪模板配置：

- 基础力量、基础智力、基础敏捷。
- 力量成长、智力成长、敏捷成长。
- 基础最大生命、基础物攻、基础魔强、基础物防、基础魔抗、基础暴击、基础生命回复、基础能量回复、基础打断阈值。
- 移动速度、攻击距离、攻击间隔。

主属性决定阶级补正和妖元补正。装备属性来自装备实例 `Stats`。

基础三维：

```text
基础力量 = 基础力量值 + 力量成长 * (等级 - 1)
基础智力 = 基础智力值 + 智力成长 * (等级 - 1)
基础敏捷 = 基础敏捷值 + 敏捷成长 * (等级 - 1)
```

## 星级倍率

```text
星级倍率 = 1.0 + (星级 - 1) * 0.085
```

星级倍率作用在基础三维上。

## 阶级配置

| 阶级 | 主属性补正 | 材料属性补正 | 百分比加成 |
| --- | --- | --- | --- |
| 白 | 0 | 0 | 0% |
| 绿 | 6 | 4 | 0% |
| 蓝 | 28 | 18 | 2% |
| 紫 | 72 | 45 | 5% |
| 红 | 150 | 92 | 9% |

阶级补正会根据主属性做权重调整：

- 力系：力量 1.25，智力 0.85，敏捷 0.90。
- 智系：力量 0.85，智力 1.25，敏捷 0.90。
- 敏系：力量 0.90，智力 0.85，敏捷 1.25。

## 最终战斗属性

合并基础、星级、阶级、妖元、装备后得到三维，再计算战斗属性：

```text
最大生命值 = 基础生命 + 力量 * 18 + 等级 * 22 + 生命加成
物理攻击力 = 基础物攻 + 力量 * 1.2 + 敏捷 * 1.8 + 物攻加成
魔法强度 = 基础魔强 + 智力 * 2.4 + 魔强加成
物理护甲 = 基础物防 + 力量 * 0.25 + 敏捷 * 0.18 + 物防加成
魔法抗性 = 基础魔抗 + 智力 * 0.22 + 魔抗加成
物理暴击 = 基础暴击 + 敏捷 * 0.32 + 暴击加成
生命回复 = 基础生命回复 + 力量 * 0.08 + 生命回复加成
能量回复 = 基础能量回复 + 能量回复加成
打断阈值 = 基础打断阈值 + 最大生命值 * 0.015 + 打断阈值加成
```

大招伤害：

```text
智系大招伤害 = 魔法强度 * 1.35 + 等级 * 4
力/敏系大招伤害 = 物理攻击力 * 1.55 + 等级 * 3
```

## UI 战力公式

UI 战力是简化评分，不等同完整战斗模拟。

```text
战力 = 80
     + 等级 * 12
     + 星级 * 16
     + 阶级战力
     + 星级额外战力
     + 阶级额外战力
     + 妖元 * 8
     + 已穿戴装备战力总和
```

阶级战力：

| 品质 | 战力 |
| --- | --- |
| 白 | 0 |
| 绿 | 20 |
| 蓝 | 48 |
| 紫 | 90 |
| 红 | 140 |

额外项：

- 星级额外战力：`(星级 - 1) * 36`
- 阶级额外战力：`(阶级 - 1) * 45`

## 装备战力

装备模板配置基础属性，不直接配置战力。装备实例保存 `Stats`，战力由属性、品质和强化等级计算：

```text
装备战力 = 基础属性战力 * 品质战力系数 + 强化等级 * 8 * 品质战力系数
```

基础属性战力：

```text
力量 * 4.2
+ 智力 * 4.2
+ 敏捷 * 4.2
+ 最大生命 * 0.18
+ 物理攻击 * 3.8
+ 魔法强度 * 3.8
+ 物理护甲 * 3.2
+ 魔法抗性 * 3.2
+ 物理暴击 * 2.5
+ 生命回复 * 2.0
+ 能量回复 * 120
+ 打断阈值 * 1.8
```

品质战力系数：

| 品质 | 系数 |
| --- | --- |
| 白 | 1.00 |
| 绿 | 1.18 |
| 蓝 | 1.42 |
| 紫 | 1.78 |
| 红 | 2.25 |

装备熔炼升阶会提升装备实例属性：

```text
新属性 = 当前属性 * 下一品质属性系数 / 当前品质属性系数
```

品质属性系数：

| 品质 | 系数 |
| --- | --- |
| 白 | 1.00 |
| 绿 | 1.22 |
| 蓝 | 1.55 |
| 紫 | 2.05 |
| 红 | 2.80 |
