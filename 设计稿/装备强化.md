# 装备强化

## 模块定位

装备强化用于消耗铜钱，提升单件装备的强化等级和装备战力。强化入口在妖怪详情的装备弹窗内。

## 强化上限

```text
装备强化等级 <= 账号等级
```

当前注册默认账号等级为 20，因此测试账号装备最高可强化到 +20。

## 强化消耗

强化消耗铜钱，按下一强化等级和品质计算：

```text
强化费用 = 下一等级 * 品质倍率
```

品质倍率：

| 品质 | 倍率 |
| --- | --- |
| 白 | 100 |
| 绿 | 140 |
| 蓝 | 220 |
| 紫 | 360 |
| 红 | 620 |

示例：

- 白装从 +0 到 +1：100 铜钱。
- 蓝装从 +4 到 +5：1100 铜钱。

## 强化收益

装备属性通过装备实例的 `TemplateId` 读取当前装备模板基础属性，并按装备实例品质进度计算。强化增加装备战力：

```text
强化战力 = 强化等级 * 8 * 品质战力系数
```

最终装备战力：

```text
装备战力 = 基础属性战力 * 品质战力系数 + 强化战力
```

品质战力系数：

| 品质 | 系数 |
| --- | --- |
| 白 | 1.00 |
| 绿 | 1.18 |
| 蓝 | 1.42 |
| 紫 | 1.78 |
| 红 | 2.25 |

基础属性战力由装备属性换算：

```text
力量 * 4.2
+ 智力 * 4.2
+ 敏捷 * 4.2
+ 最大生命 * 0.18
+ 物理攻击 * 3.8
+ 魔法强度 * 3.8
+ 物理护甲 * 3.2
+ 魔法抗性 * 3.2
+ 物理暴击 * 2.5
+ 生命回复 * 2.0
+ 能量回复 * 120
+ 打断阈值 * 1.8
```

## 装备已穿戴时

如果强化的装备正在被妖怪穿戴：

- 装备弹窗立即刷新强化等级。
- 妖怪装备槽文字刷新。
- 妖怪战力重新计算。
