# 总览

本文档概览《寻妖录》当前 Blazor Server 交互系统、LeanCLR 战斗逻辑、Pixi 战斗表现、JSON 配置系统和 LiteDB 持久化状态。

## 当前架构

- Web 交互层：`XunyaoAdventure`，使用 Blazor Server 实现登录、创建角色、主页、妖怪、背包、装备、任务、副本、阵容、战斗入口、聊天、公会、排行榜、聚妖台、邮箱和后台配置。
- 战斗表现层：`XunyaoAdventure.Battle.View`，使用 TypeScript + Pixi 渲染战斗界面。
- 战斗逻辑层：`XunyaoAdventure.Battle.Core`，由 LeanCLR 在浏览器侧执行 C# 战斗逻辑。
- 配置层：`GameConfigStore` 统一读取和保存 `App_Data/Configs/*.json`。
- 运行数据层：`GameDatabase` 统一管理 LiteDB 文件 `App_Data/GameData/xunyao.db`。

## 配置数据

配置数据使用 JSON：

```text
App_Data/Configs/monsters.json   妖怪模板
App_Data/Configs/items.json      道具、装备、碎片模板
App_Data/Configs/campaign.json   章节、关卡、奖励、敌人波次
App_Data/Configs/quests.json     主线/每日任务和奖励
App_Data/Configs/gameplay.json   初始账号、默认关卡、阵容数量、创建角色赠送妖怪、公会等级配置
App_Data/Configs/gacha.json      聚妖台奖池、消耗道具、掉落权重
```

配置文件由后台页面保存。保存后会更新内存中的配置，不需要重启服务。

## 运行数据

玩家运行数据使用 LiteDB：

```text
App_Data/GameData/xunyao.db
```

当前 LiteDB 集合：

| 集合 | Store | 内容 |
| --- | --- | --- |
| `player_accounts` | `GameAccountStore` | 账号、角色、妖怪、背包、铜钱 |
| `guilds` | `GuildStore` | 公会、成员、会长、公告、贡献、等级 |
| `chat_messages` | `ChatStore` | 世界、公会、系统聊天记录 |
| `quest_states` | `QuestStore` | 玩家任务进度和领奖状态 |
| `campaign_progress` | `CampaignStore` | 玩家已通关关卡 |
| `operation_logs` | `OperationLogStore` | 奖励领取和通关等操作日志 |
| `mail_messages` | `MailStore` | 玩家邮件、已读状态、附件领取状态 |

运行数据当前以“内存为准”。业务操作先更新内存对象，再保存 LiteDB。

## 主页入口

主页当前入口：

- 妖怪
- 任务
- 副本
- 聚妖台
- 邮箱
- 背包
- 熔炼炉
- 聊天
- 公会
- 排行榜
- 战斗
- 后台

主页聊天摘要显示玩家可见频道的最新消息：

- 世界消息对所有人可见。
- 系统消息对所有人可见。
- 公会消息只对同公会成员可见。

主页邮箱按钮会显示未读邮件和未领取附件邮件数量。

## 后台配置

后台入口：

```text
/admin
```

当前后台模块：

- 初始化配置：初始等级、初始铜钱、默认关卡、阵容数量、创建角色赠送妖怪、公会等级上限和逐级升级贡献。
- 妖怪配置：妖怪模板属性、成长、战斗资源。
- 物品配置：道具、装备、碎片模板。
- 任务配置：主线/每日任务、触发事件、前置任务、奖励。
- 副本配置：章节、关卡、奖励、首通奖励、敌人波次。
- 抽卡配置：聚妖台奖池、消耗道具、掉落项、权重。
- 邮件后台：向指定玩家或全服玩家发送邮件和附件。

后台配置页主要修改 JSON 配置。邮件后台是运行数据操作，会写入 LiteDB 邮件集合。

## 已实现系统

- 账号与角色
- 妖怪养成：升级、妖元、突破、升星
- 装备：穿戴、强化、熔炼升阶
- 背包
- 任务系统
- 章节副本和关卡掉落
- 战斗结算、首通奖励、扫荡
- 战斗选择界面的敌方波次切换
- 关卡列表显示最后一波妖怪预览
- 世界/公会/系统聊天
- 公会系统：组织、公告、贡献和等级
- 排行榜
- 聚妖台
- 邮箱系统：收件、附件领取、一键领取、删除和后台发信
- LiteDB 持久化

## 当前限制

- 聚妖台暂无保底、UP、抽卡记录和活动时间。
- 邮箱暂无过期和邮件模板配置。
- 公会尚未实现商店、公会副本、公会战和公会日志。
- 排行榜是实时读取账号数据排序，尚未实现赛季榜和历史快照。
- 聊天只保留最近 120 条消息。
- 配置数据仍是 JSON 文件，未迁入数据库。

## 好友与私聊补充

当前已实现好友系统和好友私聊：
- 主页新增好友入口；有私聊未读时显示为 `好友（N）`。
- 好友页路径为 `/friends`，支持查找玩家、发送好友申请、同意/拒绝申请、删除好友和进入私聊。
- 好友私聊路径为 `/chat/{FriendUserName}`。
- 首页聊天摘要如果最新消息是私聊，点击后进入对应好友聊天窗口。
- 好友列表展示每个好友的最近私聊内容、时间和未读数。

新增 LiteDB 集合：
| 集合 | Store | 内容 |
| --- | --- | --- |
| `friend_relations` | `FriendStore` | 双向好友关系 |
| `friend_requests` | `FriendStore` | 待处理好友申请 |
| `direct_chat_read_states` | `ChatStore` | 好友私聊已读位置 |

聊天消息集合 `chat_messages` 现在同时承载世界、公会、系统和好友私聊消息。
