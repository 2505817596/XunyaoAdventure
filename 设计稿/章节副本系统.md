# 章节副本系统

## 模块定位

章节副本系统负责把战斗包装成可选择、可解锁、可重复挑战的关卡玩法。

## 配置文件

副本配置不写在代码里，统一配置在：

```text
App_Data/Configs/campaign.json
```

后台入口：

```text
/admin/campaign
```

可配置内容：

- 章节
- 关卡
- 关卡普通掉落
- 关卡首通奖励
- 敌人波次
- 敌人模板、等级、星级、境界、站位

## 页面流程

```text
主页
 -> 副本章节列表 /campaign
 -> 章节关卡列表 /campaign/{chapterId}
 -> 点击挑战
 -> 阵容选择 /battle/formation
 -> 战斗 /battle
 -> 结算 /battle/result
```

点击关卡挑战时，会把当前关卡写入 `GameSession.SelectedStage`，同时清空上一轮阵容。

## 解锁规则

关卡配置中有 `BaseUnlocked`：

- `BaseUnlocked = true` 的关卡默认解锁。
- 其他关卡需要同章节上一关通关后解锁。

已通关状态按账号记录：

```text
userName -> cleared stage ids
```

该进度使用 LiteDB 集合 `campaign_progress` 持久化。

## 奖励规则

关卡奖励分两类：

- 普通掉落：每次胜利发放。
- 首通奖励：第一次通关时额外发放。

奖励来自关卡配置，不在代码里生成默认奖励。

当前支持奖励：

- 铜钱
- 道具

## 扫荡

已通关关卡可以扫荡。扫荡只发放普通掉落，不发放首通奖励。

## 任务联动

战斗胜利后会上报：

```text
QuestEventType.ClearStage
```

用于推进主线和每日任务中的通关目标。

## 当前限制

- 暂未支持体力消耗。
- 暂未支持指定关卡任务。
- 暂未支持关卡星级评价。
- 暂未支持章节宝箱。
