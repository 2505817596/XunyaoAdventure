# 静态资源与妖怪模型

## 模块定位

静态资源模块定义战斗单位图片资源如何放置，以及妖怪数据如何引用这些资源。

## 发布目录

战斗资源发布在 Blazor 项目的静态目录下：

```text
XunyaoAdventure/wwwroot/battle-client/
```

浏览器访问路径：

```text
/battle-client/
```

## 单位资源目录

单位资源目录结构：

```text
wwwroot/battle-client/unit/{unitAssetId}/{clip}/{frame}.png
```

示例：

```text
wwwroot/battle-client/unit/003/stand/0000.png
wwwroot/battle-client/unit/003/run/0000.png
wwwroot/battle-client/unit/003/skill0/0000.png
```

## 妖怪头像路径

妖怪 `PortraitUrl` 当前直接使用站立动作第一帧：

```text
/battle-client/unit/003/stand/0000.png
```

战斗页会从路径中解析 `unitAssetId`：

```text
/unit/003/... -> 003
```

然后传给 Pixi。

## Pixi 帧配置

Pixi 中 `UnitFrameLibrary.frameCounts` 维护每个单位每个动作的帧数。新增妖怪资源时必须同时更新这里，否则战斗中无法预加载或播放动画。

当前 `003` 已加入：

```text
003:
  stand: 12
  run: 12
  skill0: 12
```

## 新增妖怪流程

1. 把图片资源放入 `wwwroot/battle-client/unit/{新ID}/`。
2. 按动作拆分 `stand`、`run`、`skill0`。
3. 文件名使用 4 位数字补零。
4. 在 Pixi 帧配置中加入新单位的帧数。
5. 在账号初始化或妖怪配置中新增 `OwnedMonster`。
6. `PortraitUrl` 指向该单位 `stand/0000.png`。
7. 测试我的妖怪列表、妖怪详情、阵容选择和战斗头像是否都能显示。
