# 聊天系统

## 模块定位

聊天系统用于玩家之间的基础交流，以及展示系统公告。当前实现为 Blazor Server 实时刷新 + LiteDB 持久化。

## 当前频道

| 频道 | 说明 |
| --- | --- |
| 世界 | 已登录且已创建角色的玩家可以发送消息，所有玩家可见 |
| 公会 | 已加入公会的玩家可以发送消息，仅同公会成员可见 |
| 系统 | 只显示系统公告，玩家不可发送 |

## 数据模型

`ChatMessage`：

- `Id`：消息自增 ID。
- `Channel`：频道，支持 `World`、`Guild`、`System`。
- `SenderUserName`：发送者账号。
- `SenderDisplayName`：发送者角色名。
- `Content`：消息内容。
- `SentAt`：发送时间。
- `IsSystem`：是否系统消息。
- `GuildId`：公会频道所属公会 ID，世界/系统频道为空。

## 存储规则

- 使用 LiteDB 集合 `chat_messages` 持久化。
- 每条消息以 `ChatMessageDocument` 保存，消息主体使用 JSON 字符串存储。
- 内存和数据库最多保留最近 `120` 条消息。
- 启动时从 LiteDB 加载历史消息。
- 如果没有系统消息，启动时写入欢迎消息。

## 发送规则

- 必须登录。
- 必须已创建角色。
- 不能发送空消息。
- 单条消息最多 80 个字。
- 同账号同频道发送冷却为 800ms。
- 发送时会压缩多余空白，避免纯空格或大量换行刷屏。
- 公会频道发送前会校验玩家是否属于该公会。

## UI 入口

主页有“聊天”入口，进入 `/chat`。

聊天页包含：

- 世界 / 公会 / 系统频道 Tab。
- 消息列表。
- 世界和公会频道输入框、发送按钮。
- 系统频道只读提示。
- 字数统计。
- 返回主页按钮。

如果玩家未加入公会，公会频道显示“查找公会”入口，不显示其他公会消息。

## 主页摘要

主页聊天摘要显示当前玩家可见频道的最新消息：

- 世界消息对所有人可见。
- 系统消息对所有人可见。
- 公会消息只对同公会成员可见。

摘要标题会根据消息频道显示：

- 世界聊天
- 公会聊天
- 系统消息

## 刷新机制

`ChatStore` 在消息变化时触发 `MessagesChanged` 事件。聊天页和主页订阅事件后调用 `InvokeAsync` 刷新 UI，所以多个 Blazor Server 会话可以看到实时新增消息。
