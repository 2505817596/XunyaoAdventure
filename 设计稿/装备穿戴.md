# 装备穿戴

## 模块定位

装备穿戴发生在妖怪详情页。装备不是升阶消耗品，穿上后加战力和战斗属性，后续可以卸下或替换。

## 装备槽位

每个妖怪拥有 6 个装备槽：

| SlotKey | 名称 |
| --- | --- |
| `weapon` | 武器 |
| `armor` | 护甲 |
| `necklace` | 饰品 |
| `boots` | 鞋子 |
| `relic` | 法器 |
| `soul` | 命星 |

## 穿戴规则

- 装备只能穿到相同 `SlotKey` 的槽位。
- 每个槽位同时只能穿 1 件装备。
- 装备如果已被其他妖怪穿戴，不能直接穿到当前妖怪。
- 当前槽位已有装备时，穿新装备会自动把旧装备卸回背包。
- 穿戴成功后更新妖怪装备栏和战力。

## 卸下规则

- 点击已穿戴装备槽打开弹窗。
- 弹窗显示当前装备属性。
- 点击卸下装备后，槽位变空。
- 背包装备的 `EquippedMonsterId` 置空。
- 更新妖怪战力。

## 空槽弹窗

点击空装备槽时：

- 弹窗显示该槽位可穿戴装备列表。
- 只展示未穿戴或属于当前妖怪的同槽位装备。
- 上方显示当前选中装备详情。
- 点击“穿戴”装备后关闭弹窗并刷新详情。

## 初始状态

创建角色时不自动赠送装备，也不自动穿戴装备。

装备来源：

- GM 发放
- 任务奖励
- 副本掉落
- 活动或邮件

妖怪创建后 6 个装备槽均为空。
