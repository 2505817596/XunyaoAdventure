# 装备穿戴

## 模块定位

装备穿戴发生在妖怪详情页。装备不是升阶消耗品，穿上后加战力和战斗属性，后续可以卸下或替换。

## 装备槽位

每个妖怪拥有 6 个装备槽：

| SlotKey | 名称 |
| --- | --- |
| `weapon` | 武器 |
| `armor` | 护甲 |
| `necklace` | 饰品 |
| `boots` | 鞋子 |
| `relic` | 法器 |
| `soul` | 命星 |

## 穿戴规则

- 装备只能穿到相同 `SlotKey` 的槽位。
- 每个槽位同时只能穿 1 件装备。
- 装备如果已被其他妖怪穿戴，不能直接穿到当前妖怪。
- 当前槽位已有装备时，穿新装备会自动把旧装备卸回背包。
- 穿戴成功后更新妖怪装备栏和战力。

## 卸下规则

- 点击已穿戴装备槽打开弹窗。
- 弹窗显示当前装备属性，并显示“已装备”标记。
- 点击卸下装备后，槽位变空。
- 背包装备的 `EquippedMonsterId` 置空。
- 更新妖怪战力。

## 空槽弹窗

点击空装备槽时：

- 先打开装备列表悬浮框。
- 列表只展示未穿戴、且 `SlotKey` 与当前槽位一致的装备。
- 装备格子边框按装备品质显示颜色。
- 如果没有可穿戴装备，只显示“暂无可穿戴装备”，不显示空白补位格子。
- 点击列表中的装备，不直接穿戴，而是在列表上方叠加装备详情弹窗。
- 装备详情弹窗显示选中装备的名称、等级、品质、战力、基础属性、词缀效果和强化费用。
- 点击“穿戴”后执行穿戴，关闭装备详情弹窗和装备列表悬浮框，并刷新妖怪详情。

## 替换流程

点击已穿戴装备槽时：

- 先打开当前装备详情弹窗。
- 弹窗显示“替换”“强化”“卸下”按钮。
- 点击“替换”后关闭当前装备详情弹窗，并打开该槽位可穿戴装备列表悬浮框。
- 点击列表中的装备后，装备列表保持打开，并在上层打开装备对比详情弹窗。
- 对比详情弹窗上半部分显示当前已装备装备，下半部分显示候选装备。
- 候选装备详情中点击“替换”后执行穿戴，新装备替换旧装备，旧装备回到背包。
- 替换成功后关闭装备详情弹窗和装备列表悬浮框，并刷新妖怪详情。

## 初始状态

创建角色时不自动赠送装备，也不自动穿戴装备。

装备来源：

- GM 发放
- 任务奖励
- 副本掉落
- 活动或邮件

妖怪创建后 6 个装备槽均为空。
