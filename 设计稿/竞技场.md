# 竞技场

## 模块定位

竞技场是异步 PVP 挑战模块。玩家从竞技场首页选择对手，进入阵容选择页后使用已有战斗表现和 LeanCLR 战斗逻辑完成一场玩家阵容对玩家阵容的战斗。战斗结束后根据胜负调整竞技积分，并进入竞技结算页。

当前版本不做实时匹配、赛季、挑战次数限制和防守日志，先实现基础挑战闭环。

## 页面入口

主页新增“竞技场”入口。

页面路径：
```text
/arena
/arena/result
```

排行榜页新增“竞技场”榜单 Tab，也可从竞技场首页点击“竞技排行”进入：
```text
/rankings?board=arena
```

## 首页展示

竞技场首页展示：

- 当前排名
- 当前积分
- 胜负场次
- 刷新对手
- 竞技排行入口
- 3 个可挑战对手

对手卡片展示：

- 对手角色名
- 对手竞技排名
- 对手竞技积分
- 对手总战力
- 对手最强妖怪
- 对手防守阵容头像

## 对手选择逻辑

竞技场对手由 `ArenaStore.GetOpponents(...)` 生成。

排序和选择规则：

1. 先使用 `BuildRankings()` 生成竞技排名。
2. 排名规则为竞技积分降序，其次总战力降序，再按更新时间升序。
3. 找到当前玩家自己的排名。
4. 排除当前玩家。
5. 优先选择排名最接近当前玩家的账号。
6. 真实玩家不足 3 个时，使用当前玩家阵容生成练习对手。

因此首页对手列表是“接近当前排名的挑战对象”，不是从第 1 名开始的排行榜列表。完整竞技排行在排行榜页展示。

## 挑战流程

1. 玩家在 `/arena` 选择对手。
2. `ArenaStore.CreateBattleSelection(...)` 固化本次对手信息和对手阵容。
3. `GameSession.SelectArenaBattle(...)` 保存竞技场战斗上下文。
4. 跳转 `/battle/formation` 选择己方阵容。
5. 进入 `/battle` 后通过 `BattleDemoSetupFactory.CreateArenaSetupBytes(...)` 构造玩家阵容对玩家阵容的战斗。
6. 战斗结束后 `Battle.razor` 判断当前为竞技场上下文，调用 `ArenaStore.CompleteChallenge(...)`。
7. 结算结果写入 `GameSession.LastArenaBattleResult` 并跳转 `/arena/result`。

## 战斗显示一致性

竞技场首页和阵容选择页显示对手妖怪的 `PortraitUrl`。

战斗场景中，Blazor 会把对手阵容生成 `enemies` 元数据传给 battle-view：

- `unitId`
- `name`
- `portraitUrl`
- `unitAssetId`
- `stage`
- `star`

前端 `main.ts` 会把 `heroes` 和 `enemies` 一起写入 `unitMetadata`。敌方 TeamB 单位渲染时读取对应 `unitAssetId`，避免回退到默认敌方资源，保证首页对手和战斗场景里的单位资源一致。

当前 unitId 映射依赖核心战斗生成顺序：

- 我方单位先生成，unitId 为 `1..N`
- 敌方第一波随后生成，unitId 为 `N+1..N+M`

如果未来战斗核心改变单位生成顺序，需要同步调整前端元数据映射方式，或把资源标识写入战斗协议。

## 积分结算

竞技场资料由 `ArenaProfile` 表示：

- `UserName`
- `RoleName`
- `Score`
- `Wins`
- `Losses`
- `ChallengeCount`
- `UpdatedAt`

首次进入竞技场时自动创建资料，初始积分为：

```text
1000 + 总战力 / 25
```

胜负积分变化由 `ArenaStore.ResolveScoreDelta(...)` 计算：

- 胜利基础分为 `+18`
- 失败基础分为 `-10`
- 根据双方积分差增加或减少变化幅度
- 失败后积分最低为 0

## 竞技排行榜

竞技排行榜由 `ArenaStore.GetRankings(...)` 实时读取 `arena_profiles` 和账号战力生成。

展示字段：

- 排名
- 角色名
- 积分
- 胜负
- 总战力

## 持久化

竞技场资料保存到 LiteDB 集合：

```text
arena_profiles
```

文档类型：

```csharp
ArenaProfileDocument
```

字段：

- `UserName`
- `RoleName`
- `Score`
- `Wins`
- `Losses`
- `ChallengeCount`
- `UpdatedAt`

## 当前限制

- 没有赛季和每日重置。
- 没有挑战次数、冷却和门票消耗。
- 没有防守阵容独立保存，当前使用账号最强妖怪自动组成防守阵容。
- 没有防守战报。
- 没有排名奖励。
- 练习对手由当前玩家阵容缩放生成，仅用于真实玩家不足时补足列表。
