# 装备熔炼升阶

## 模块定位

装备升阶不在装备详情里做，而是在大厅的“熔炼大炉子”页面中完成。当前设计为指定一件主装备，再消耗若干同阶材料装备，把主装备提升到下一品质。

## 品质链

```text
白 -> 绿 -> 蓝 -> 紫 -> 红
```

红色为当前最高品质，不能继续升阶。

## 选择规则

- 必须先选择 1 件主装备。
- 主装备不能作为材料消耗。
- 材料必须和主装备同品质。
- 已穿戴装备不能作为材料。
- 材料数量必须刚好满足需求。
- 升阶后主装备保留，材料装备从背包删除。

## 消耗规则

根据主装备当前品质决定材料数量：

| 当前品质 | 目标品质 | 材料数量 |
| --- | --- | --- |
| 白 | 绿 | 1 |
| 绿 | 蓝 | 2 |
| 蓝 | 紫 | 3 |
| 紫 | 红 | 4 |
| 红 | 无 | 0 |

## 升阶结果

升阶成功后：

- 主装备品质变为下一品质。
- 主装备名称变为“新品质 + 部位名”，例如“绿武器”。
- 强化等级保留。
- 装备实例属性按品质成长比例放大。
- 装备战力按新属性、新品质和强化等级重算。

品质属性系数：

| 品质 | 属性系数 |
| --- | --- |
| 白 | 1.00 |
| 绿 | 1.22 |
| 蓝 | 1.55 |
| 紫 | 2.05 |
| 红 | 2.80 |

升阶属性缩放：

```text
新属性 = 当前属性 * 下一品质属性系数 / 当前品质属性系数
```

- 属性文本按新属性、新品质和强化等级重算。
- 如果主装备已被妖怪穿戴，则刷新该妖怪战力。

## 熔炼界面

- 页面标题：熔炼大炉子。
- 九宫格：
  - 第一个格子为主装备。
  - 后续格子为材料装备。
- 下方装备列表用于选择主装备和材料。
- 预览区域显示主装备当前品质、目标品质和所需材料数量。
