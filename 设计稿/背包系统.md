# 背包系统

## 模块定位

背包负责查看玩家拥有的道具、装备和碎片。当前背包页只做展示和选择，不在背包页直接使用道具。

## 页面入口

主页入口：

```text
/
 -> 背包
```

页面路由：

```text
/backpack
```

## 背包分类

背包使用 Tab：

- 道具
- 装备
- 碎片

当前没有单独的“碎片和碎片”重复分类，碎片统一放在碎片 Tab。

## 道具

运行模型：

```csharp
BackpackConsumableItem
```

字段：

- `TemplateId`
- `Name`
- `Quantity`
- `EffectType`
- `EffectValue`
- `Description`

道具名称、图片路径、效果和描述通过 `TemplateId` 读取当前物品配置。

背包页只显示数量大于 0 的道具。

道具模板配置在：

```text
App_Data/Configs/items.json
```

当前常用效果类型：

| EffectType | 含义 |
| --- | --- |
| `None` | 无效果 |
| `MonsterExp` | 妖怪经验 |
| `DemonEssence` | 妖元材料 |
| `BreakthroughPill` | 突破材料 |
| `SoulStone` | 升星材料 |

道具来源：

- 任务奖励
- 副本奖励
- 聚妖台掉落
- 邮件附件
- 后台/GM 发放
- 后续活动系统

道具也可以作为聚妖台奖池消耗物。

## 装备

运行模型：

```csharp
BackpackEquipmentItem
```

字段：

- `InstanceId`
- `TemplateId`
- `QualityOverride`
- `EquippedMonsterId`
- `UpgradeLevel`

装备名称、部位、图片路径、基础属性和展示属性通过 `TemplateId` 读取当前装备模板。装备默认品质为白色；熔炼升阶后的品质由 `QualityOverride` 保存。

装备页展示：

- 图标
- 品质颜色框
- 强化等级
- 是否已穿戴
- 详情区显示部位、品质、强化、战力、属性、穿戴对象

当前装备来源主要来自配置和后续玩法扩展。聚妖台暂未支持装备掉落。

## 碎片

运行模型：

```csharp
BackpackFragmentItem
```

字段：

- `TemplateId`
- `Name`
- `Quantity`
- `Quality`
- `Description`

碎片名称、图片路径、品质和描述通过 `TemplateId` 读取当前碎片配置。

碎片来源：

- 副本奖励
- 聚妖台掉落
- 任务奖励
- 邮件附件
- 后续活动系统

碎片当前只展示，合成妖怪逻辑尚未实现。

## 布局

- 上方是选中物品详情。
- 下方是正方形格子列表。
- 点击下方格子会更新上方详情。
- 页面宽度遵循 WAP 容器规则，桌面端居中，最大宽度 430px。

## 当前限制

- 背包页不能直接使用道具。
- 暂无道具出售。
- 暂无道具排序筛选。
- 暂无装备来源记录。
- 暂无碎片合成。
