# 总览

本文档概览当前《寻妖录》Blazor Server 交互系统、LeanCLR 战斗逻辑、Pixi 战斗表现、配置系统以及 LiteDB 持久化状态。

## 当前架构

- Web 交互层：`XunyaoAdventure`，使用 Blazor Server 实现登录、创建角色、主页、妖怪、背包、装备、任务、副本、阵容、战斗入口、聊天、公会、排行榜和后台配置。
- 战斗表现层：`XunyaoAdventure.Battle.View`，使用 TypeScript + Pixi 渲染战斗界面。
- 战斗逻辑层：`XunyaoAdventure.Battle.Core`，由 LeanCLR 在浏览器侧执行 C# 战斗逻辑。
- 配置层：`GameConfigStore` 统一读取和保存 `App_Data/Configs/*.json`。
- 运行数据层：`GameDatabase` 统一管理 LiteDB 文件 `App_Data/GameData/xunyao.db`。

## 数据分类

配置数据继续使用 JSON：

```text
App_Data/Configs/monsters.json   妖怪模板
App_Data/Configs/items.json      道具、装备、碎片模板
App_Data/Configs/campaign.json   章节、关卡、掉落、敌人波次
App_Data/Configs/quests.json     主线/每日任务及奖励
App_Data/Configs/gameplay.json   初始账号、默认关卡、阵容数量、初始赠送妖怪
```

玩家运行数据使用 LiteDB：

```text
App_Data/GameData/xunyao.db
```

当前 LiteDB 集合：

| 集合 | 内容 |
| --- | --- |
| `player_accounts` | 账号、角色、妖怪、背包、铜钱等账号快照 |
| `guilds` | 公会、成员、会长、公告 |
| `chat_messages` | 世界、公会、系统频道聊天记录 |
| `quest_states` | 玩家任务进度和领奖状态 |
| `campaign_progress` | 玩家已通关关卡 |

## 主页入口

主页当前入口：

- 妖怪
- 任务
- 副本
- 背包
- 熔炼炉
- 聊天
- 公会
- 排行榜
- 战斗
- 后台

主页聊天摘要显示玩家可见频道的最新消息：

- 世界消息对所有人可见。
- 系统消息对所有人可见。
- 公会消息只对同公会成员可见。

## 后台配置

后台入口：`/admin`

当前后台模块：

- 初始化配置：初始等级、初始铜钱、默认关卡、阵容数量、创建角色赠送妖怪。
- 妖怪配置：妖怪模板属性、成长、战斗资源。
- 物品配置：道具、装备、碎片模板。
- 任务配置：主线/每日任务、触发事件、前置任务、奖励。
- 副本配置：章节、关卡、掉落、首通奖励、敌人波次。

后台配置只修改 JSON 配置，不直接修改玩家运行数据。

## 已实现系统

- 账号与角色
- 妖怪养成：升级、妖元、突破、升星
- 装备：穿戴、强化、熔炼升阶
- 背包
- 任务系统
- 章节副本和关卡掉落
- 战斗结算、首通奖励、扫荡
- 世界/公会/系统聊天
- 公会基础版
- 排行榜
- LiteDB 持久化

## 当前限制

- 公会只有基础组织能力，尚未实现捐献、商店、公会副本、公会战。
- 排行榜是实时读取账号数据排序，尚未实现赛季榜和历史快照。
- 聊天只有最近 120 条消息。
- 配置数据仍是 JSON 文件，未迁入数据库。
