# 排行榜

## 模块定位

排行榜用于展示玩家成长结果，当前实现为实时榜，不做赛季快照。

## 页面入口

主页有“排行榜”入口。

页面路径：

```text
/rankings
```

## 当前榜单

| 榜单 | 排序规则 |
| --- | --- |
| 总战力 | 总战力降序，其次最强妖怪战力降序 |
| 最强妖怪 | 最强单只妖怪战力降序，其次总战力降序 |
| 等级 | 账号等级降序，其次总战力降序 |
| 铜钱 | 铜钱降序，其次总战力降序 |

同分时按创建角色时间较早优先。

## 数据来源

排行榜直接读取 `GameAccountStore.GetRankings(...)`。

`GameAccountStore` 的账号数据已持久化到 LiteDB 集合 `player_accounts`。

当前不会单独保存排行榜快照。

## 展示字段

`RankingEntry`：

- `Rank`
- `UserName`
- `RoleName`
- `Level`
- `Copper`
- `TotalPower`
- `StrongestMonsterPower`
- `StrongestMonsterName`
- `CreatedAt`

页面会标记当前玩家为“自己”。

## 当前限制

- 只显示已创建角色的账号。
- 没有赛季榜。
- 没有历史排名变化。
- 没有分页，目前最多取前 50 名。

## 后续扩展

- 赛季排行榜。
- 每日/每周排行快照。
- 公会排行榜。
- 通关进度排行榜。
- 排名奖励。

## 竞技场排行榜补充

排行榜页现在包含“竞技场”Tab。竞技场榜单由 `ArenaStore.GetRankings(...)` 生成，数据来源为 `arena_profiles` 和账号总战力。

竞技榜排序规则：竞技积分降序，其次总战力降序，再按竞技资料更新时间升序。展示字段包括排名、角色名、积分、胜负和总战力。

竞技场首页的对手列表不是完整排行榜，而是优先展示排名接近当前玩家的可挑战对象。完整竞技排行以排行榜页为准。
