# 初始化配置

## 模块定位

初始化配置用于管理新账号创建角色时获得的内容。

## 配置文件

路径：

```text
App_Data/Configs/gameplay.json
```

结构：

```json
{
  "version": 1,
  "initialRole": {
    "monsterTemplateIds": [
      "monster-1"
    ]
  }
}
```

字段说明：

- `version`：配置版本。
- `initialRole.monsterTemplateIds`：创建角色时赠送的妖怪模板 ID 列表。

## 后台页面

路径：

```text
/admin/gameplay
```

功能：

- 显示所有妖怪模板。
- 使用多选下拉框选择创建角色赠送妖怪。
- 保存后写入 `gameplay.json`。

## 创建角色流程

创建角色时：

1. 写入角色名和创建时间。
2. 读取 `gameplay.json` 的 `initialRole.monsterTemplateIds`。
3. 按模板 ID 读取 `monsters.json`。
4. 为玩家创建对应 `OwnedMonster`。
5. 第一个赠送妖怪设为收藏。

如果初始化配置为空，创建角色成功后初始妖怪列表为空。

装备、道具、碎片由 GM、任务、副本掉落、活动、邮件等系统发放。
